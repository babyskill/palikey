# PaliKey (codename)

One Pāḷi input method for every platform — one Rust engine, one typing scheme
family, native shells for Windows, macOS, Linux, Android, iOS and Web.

See [DESIGN.md](DESIGN.md) for the full design: fragmentation analysis of the
current Pāḷi keyboards, the vnkey (marixdev/vnkey) architecture study,
input schemes (Velthuis / PaliTelex / SIL), and the Phase 0–4 roadmap.

Status: Phase 0 — engine scaffold. Clean-room implementation (MIT), inspired by
vnkey's core-and-shell architecture; no vnkey code is used (vnkey is GPL-3.0).
